# Project constitution

Version 1 · 1 October 2026 · established from the user's master production specification.

## Immutable product purpose

The learner prepares for Telangana Police Sub-Inspector or Constable. The initial domain is Telangana Movement & State Formation. External examinations are research inputs only, never additional learner preparation targets.

Accuracy, provenance, exam relevance, content coverage, learner diagnosis, adaptive training, diversity and retention take priority over decoration. Generated practice must never be called an authentic PYQ. Missing source evidence, keys, historical facts and current-affairs links remain explicitly unknown or held for review.

## Teaching contract

Every wrong answer must immediately teach in simple Indian English: state the wrong choice and correct answer; explain both concepts; point to the exact clue in this question; explain why the wrong choice may look tempting without claiming to read the learner's mind; give a concrete “if the question asks this, choose this” contrast; and offer an appropriate follow-up. Do not hide this essential repair behind an accordion. Longer sources and all-option analysis can expand separately.

One mistake supports an explanation, not a definite diagnosis. Repeated, directional option evidence can justify a comparison drill. Never equate slow answers, tab backgrounding or guessing patterns with a certain mental state.

## Engineering contract

Preserve existing learner data and useful source research. Use versioned database content, stable IDs, source registration, document hashes, canonical question fingerprints, explicit publication review and bounded server retrieval. Do not bundle the whole corpus in the learner client. Exact repetition needs an educational reason; prefer an unseen reviewed variant. Never increase question counts with duplicate or unverified content just to pass a scale claim.

Published questions retain original source classifications. Answer/explanation changes increment content versions; attempts retain their scoring version. AI research, drafting, validation and publication are separate responsibilities. No unattended model output publishes itself.

## Session protocol

Before development, read this file, PROJECT_STATE.md, ARCHITECTURE.md, DECISIONS.md, SOURCE_REGISTRY.md, CONTENT_COVERAGE.md, QUESTION_MODEL_CATALOG.md, ADAPTIVE_ENGINE_SPEC.md and NEXT_ACTIONS.md; inspect the implementation and run baseline checks. Repository evidence takes precedence over chat memory. Missing documentation must be created honestly, not filled with invented completion claims.

Before stopping, update PROJECT_STATE.md, DECISIONS.md, KNOWN_GAPS.md, NEXT_ACTIONS.md and VALIDATION_REPORT.md with implemented changes, executed tests, open gaps and the exact next action. Keep a recoverable checkpoint. A passed scale fixture is not a real verified corpus; local profiles are not production authentication; a schema file is not a deployed cloud backend.

Explicit user changes can revise this constitution. Record the decision and preserve the established purpose unless the user explicitly changes it.
